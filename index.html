맞춤 기준 — 전기전자 제어 · 회로설계 2~3년 · 생산관리 1년 3개월 경력 · 희망지역 서울/경기 · 정규직만 (계약직·인턴·파견 제외) · 마감된 공고는 자동으로 숨겨요

사람인·잡코리아·원티드·캐치는 매일 자동 수집돼요. 기업 규모 표시는 데이터를 공개하는 캐치 공고에서만 가능해요. 블라인드 링크는 검색 결과로 바로 연결해줄 뿐, 연봉 같은 실제 수치는 블라인드 로그인 뒤에만 보여서 자동으로 가져올 수는 없어요. 자소설닷컴은 로그인 세션이 있어야 데이터를 주는 사이트라 자동 수집이 안 돼서 사이트에서 직접 확인하는 걸 권장하고, 인크루트는 검색 페이지로 바로가기를 둘게요.
